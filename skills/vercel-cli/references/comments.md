# Vercel Toolbar Comments

The CLI manages existing Toolbar threads; new threads are created through the Toolbar.

Review the resolved project and branch before treating a thread list as complete. Checkout-based resolution can narrow results to the current Git branch, and a thread URL can supply its team context.

Inspect the thread before changing individual messages. Editing content preserves attachments; deleting a message is irreversible. Bulk thread operations can partially succeed even when the command exits nonzero, so inspect individual results before retrying.

Attachments use remote HTTPS URLs rather than local file uploads. Opening a thread in the dashboard is a browser action, not a machine-readable query.
