# Modulato Example

This directory is a brief example of a [Modulato](https://modulato.org) site that can be deployed to Vercel with zero configuration.

## Deploy Your Own

Deploy your own Modulato project with Vercel.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/vercel/vercel/tree/main/examples/modulato)

### How We Created This Example

To get started with Modulato on Vercel, you can use [create-modulato](https://www.npmjs.com/package/create-modulato) to initialize the project:

```shell
$ npm create modulato@latest
```

### Deploying From Your Terminal

Once initialized, you can deploy the Modulato example with just a single command:

```shell
$ vercel
```
